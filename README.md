# SQL Job Market Analysis

## About the Project

This project analyzes job posting data using SQL to explore the job market, companies, skills, and job opportunities.

## Tools Used

- PostgreSQL
- SQL
- Git
- GitHub

## Project Contents

- Database creation and setup
- Table creation
- Data modification
- Job posting data
- Company data
- Skills data
- SQL analysis queries

## Key Analysis

The project uses SQL techniques such as:

- SELECT
- JOIN
- GROUP BY
- Aggregate functions
- CTEs
- Subqueries
- Data analysis

## Goal

The goal of this project is to practice SQL and extract useful insights from job market data.
